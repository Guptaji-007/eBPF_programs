# eBPF Program Example (libbpf Skeleton Workflow)

This repository demonstrates a **minimal eBPF workflow** using **clang**, **bpftool**, and **libbpf**.
The program loads an eBPF program into the kernel and prints debug output via `trace_pipe`.

---

## Overview

Workflow:

```
Write .bpf.c
   ↓
clang -target bpf
   ↓
bpftool gen skeleton
   ↓
gcc loader.c
   ↓
sudo ./loader
   ↓
cat trace_pipe
```

---

## 📁 Files

| File            | Description                                   |
| --------------- | --------------------------------------------- |
| `myprog.bpf.c`  | eBPF program (runs in kernel space)           |
| `myprog.bpf.o`  | Compiled eBPF object file                     |
| `myprog.skel.h` | Auto-generated libbpf skeleton                |
| `loader.c`      | User-space program that loads & attaches eBPF |
| `loader`        | Compiled loader binary                        |
| `README.md`     | This documentation                            |

##  Requirements

Make sure the following are installed:

* Linux kernel **5.8+**
* `clang`
* `llvm`
* `bpftool`
* `libbpf-dev`
* `gcc`
* Root privileges (`sudo`)

On Debian/Ubuntu:

```bash
sudo apt install clang llvm bpftool libbpf-dev linux-headers-$(uname -r)
```

---

## Step 1 — Create the eBPF Program

Create the file:

```bash
nano myprog.bpf.c
```

Write your eBPF code in this file (tracepoint, kprobe, etc.).

---

##  Step 2 — Compile the eBPF Program

Compile the program for the BPF target:

```bash
clang -O2 -g -target bpf -c myprog.bpf.c -o myprog.bpf.o
```

This produces the eBPF object file.

---

## Step 3 — Generate the libbpf Skeleton

Generate the skeleton header:

```bash
bpftool gen skeleton myprog.bpf.o > myprog.skel.h
```

This skeleton simplifies loading, attaching, and managing the eBPF program.

---

## ‍Step 4 — Write the User-Space Loader

Create `loader.c`.

This program:

* Includes `myprog.skel.h`
* Loads the eBPF program
* Attaches it to the kernel
* Keeps it running

---

## Step 5 — Compile the Loader

Compile the user-space loader:

```bash
gcc -O2 -g loader.c -o loader -lbpf
```

---

## Step 6 — Run the Program

Run the loader (requires root):

```bash
sudo ./loader
```

---

## View eBPF Output

In **another terminal**, read the trace output:

```bash
sudo cat /sys/kernel/debug/tracing/trace_pipe
```

You should see messages generated by your eBPF program.

---

## Notes

* `trace_pipe` shows live kernel tracing output.
* Press `Ctrl+C` to stop tracing.
* The loader must stay running for the eBPF program to remain attached.
* Debug messages typically use `bpf_printk()`.
